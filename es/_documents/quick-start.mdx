# 开发指南

跟随以下的步骤，快速上手组件库的使用。

## 安装

无需再单独安装以下 3 个基础包，由此物料库统一管理依赖：

- 基础组件库@arco-design/web-react
- 火山主题包@arco-design/theme-volcengine-ui-v3（继承自源力主题包）
- 源力图标库@arco-design/iconbox-react-ve-o-design

```bash
yarn add @cloud-materials/common
```

\*\*注意：此组件库尚未开源，需要使用内部 BNPM 源安装。

```bash
npm config set registry=https://bnpm.byted.org
```

### peerDependencies 依赖

**react**: >= 16.8
**react-dom**: >= 16.8
**typescript**: >= 4.1

## 使用组件

统一物料（C 开头）、arco 组件都从@cloud-materials/common 统一导出引用

```tsx
import React from 'react';
import { CCopy, Message } from '@cloud-materials/common'; //使用物料、arco组件
import type { ObjectValueType } '@cloud-materials/common/arco/es/InputTag/interface'; //使用arco es文件

export default () => (
  <CCopy
    text="hi, it's copy"
    triggerIcon={<IconCopy />}
    onCopy={(text, result) => Message.info(`${text} - ${result ? '复制成功' : '复制失败'}`)}
  />
);
```

## 使用 icon

arco 图标、源力图标，都可从统一物料引入

```ts
import { IconAlignLeft } from '@cloud-materials/common/arco/icon'; //使用arco图标
import { IconCopy } from '@cloud-materials/common/ve-o-iconbox';  //使用源力图标
```

## 使用样式

引入带火山主题样式的全局样式：
以下 less 或 css 引用二选一，无需再单独引入 arco 样式或源力/火山等任何 3.0 主题样式

⚠️ 引入**less**需要`webpack5`，因为 less 文件内部的 import 语法去掉了"~"前缀，如果暂时无法迁移到 webpack5，请先使用 css

```ts
import '@cloud-materials/common/dist/css/index.less';
import '@cloud-materials/common/dist/css/index.css';
```

使用原子样式：

```tsx
<Modal className="c-m-icon" />
```

### 样式&主题排障

❓ 未生效或与预期不符

💡 需要排查是否引用了 arco 的样式如`import "@arco-design/web-react/dist/css/arco.css"`导致主题样式被覆盖，如果未在代码中找到类似的代码，可能需要排查 npm 包中是否有类似的引用，如基于 arco 二次开发的物料库等，或者是项目的统一入口、脚手架等。
如果是引用的三方包不好排查，可以使用插件：https://bnpm.bytedance.net/package/@rdservices/webpack-theme-ve-o-design-fix-plugin自动清除额外的arco样式引用

❓ 与设计稿不一致

- 💡 源力/火山主题包会定期进行更新，统一物料可能出现版本滞后的情况，等待统一物料发版或直接进行反馈；
- 💡 进入 [🔗 源力设计体系](https://arco.bytedance.net/themes/design/869/setting/base/Color) ，检查设计稿一致是否最和最新的源力设计一致，若出现不一致可以直接找到设计同学反馈设计与规范不符或者搜索`源力设计体系-规范问题反馈群`进行反馈；
- 💡 发起统一物料的 oncall 进行问题反馈。

## 全局源力 icon 替换
目前有两种方式处理源力主题 icon
1. [使用 webpack 插件（推荐）](https://bytedance.larkoffice.com/wiki/wikcnLA7Pk0B2WHjRu12ApL1xJP#VqWqdgy4Ioywy0xoB2acZMwanSh)
2. 使用`CConfigProvider` 组件包裹。

方式1的原理是替换 arco 本身的 icon 导入路径为源力主题包 icon 的路径，替换更全面。方式2是手动的方式，部分icon无法替换（arco未开口子）。

## 国际化
国际化能力由 `CConfigProvider` 提供。
```tsx
import { CConfigProvider } from '@cloud-materials/common';
import zhCN from '@cloud-materials/common/es/locales/zh-CN';
import enUS from '@cloud-materials/common/es/locales/en-US';

export function App() {
  return (
    <CConfigProvider locale={locale === 'en-US' ? enUS : zhCN;}>
      children
    </CConfigProvider>
  )
}
```
更多 demo 请参考 CConfigProvider
## 使用 hooks

统一物料库基于 Headless UI 开发理念，部分组件逻辑部分抽离，可单独使用其提供的 hooks，搭配自定义 UI 实现更多组件扩展

```tsx
import React from 'react';
import { useCCopy, Message } from '@cloud-materials/common';

export default () => {
  const [, controls] = useCCopy({
    text: '我是想放在文本上点击复制的内容',
    onCopy: (_, Result) => (Result ? Message.success('操作成功') : Message.error('操作失败')),
  });

  return (
    <p onClick={controls.handleCopy} style={{ cursor: 'pointer' }}>
      Hi, Headless UI 点击复制
    </p>
  );
};
```

## 按需加载

https://arco.design/docs/designlab/use-theme-package 目前主题包+样式按需存在问题待官方支持

```ts
const ArcoWebpackPlugin = require('@arco-plugins/webpack-react');
// webpack config
{
  plugins: [
    // 使用 babel-plugin-import 按需加载组件和样式
    [
      'babel-plugin-import',
      {
        libraryName: '@cloud-materials/common',
        libraryDirectory: 'es',
        camel2DashComponentName: false,
        style: true, // 样式按需加载
      },
    ],
    // 搭配指定主题包
    new ArcoWebpackPlugin({
        theme: '@arco-design/theme-volcengine-ui-v3'
    })
  ]
}
```
